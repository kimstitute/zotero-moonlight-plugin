# 로고

금빛 유리 초승달이 빨간 Zotero Z를 감싸는 3D 아이콘입니다. 광택과 은은한 반투명 유리 재질을 사용하며 배경은 실제 PNG 알파 채널로 투명하게 처리합니다.

- 원본 이미지: `assets/moonlight-zotero-glossy.png`
- 배포 크기: `addon/content/icons/icon-{16,32,48,96,128,256}.png`
- 사용 위치: 플러그인 관리자, 항목 메뉴, 설정 메뉴, 내부 탭, 설정 화면.
- 생성 도구: 내장 Imagegen.
- 디자인 프롬프트 요약: “A polished translucent champagne-yellow glass crescent embracing a ruby-red Zotero Z; clean glossy bevels, transparent background, no floor or shadow.”

연동 플러그인을 위해 생성한 비공식 디자인이며 Moonlight 또는 Zotero의 공식 제휴를 나타내지 않습니다. 배포 이미지는 픽셀과 표시를 위한 필수 정보만 포함하고 부가 메타데이터는 제거했습니다.
