# 로고

보라색 배경의 노란 달 중앙에 빨간 Zotero Z를 배치한 광택 있는 3D 아이콘입니다.

- 원본 이미지: `assets/moonlight-zotero-glossy.png`
- 배포 크기: `addon/content/icons/icon-{16,32,48,96,128,256}.png`
- 사용 위치: 플러그인 관리자, 항목 메뉴, 설정 메뉴, 내부 탭, 설정 화면.

연동 플러그인을 위해 생성한 비공식 디자인이며 Moonlight 또는 Zotero의 공식 제휴를 나타내지 않습니다. 배포 이미지는 픽셀 데이터와 표시를 위한 필수 정보만 포함합니다.
