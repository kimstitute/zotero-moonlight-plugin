# 호환성 및 검증

## 지원 범위

- Windows, Zotero 9.0 계열. 검증 버전: Zotero 9.0.6.
- 외부 브라우저: Chrome 또는 Edge. Edge는 추가 수동 검증이 필요합니다.
- 내부 탭: Moonlight 웹 리더를 사용하며 브라우저 확장은 필요하지 않습니다.
- macOS, Linux, 다른 Zotero 버전은 미검증입니다.

## v0.2.1 검증

- 타입 검사, 자동 테스트 27개, 번들 문법 검사 및 XPI 패키징 통과.
- 별도 테스트 프로필에서 실제 Zotero 검사 24개 통과.
- 메뉴 등록, 설정 저장, 설정 로고 로딩, 내부 탭 로고, 웹 리더 프레임 로딩 확인.
- 같은 논문의 탭 재사용, 웹 콘텐츠 권한, 비활성화 시 정리 확인.
- 테스트에는 공개 샘플 URL과 가상의 항목 식별자를 사용합니다.

## 제약

- 내부 탭의 로그인 상태는 외부 브라우저와 별개입니다.
- Google 로그인 팝업, 로그인 후 구독 AI 기능은 추가 수동 확인이 필요합니다.
- 출판사 로그인 및 기관 인증에 따라 원문 페이지에서 직접 열어야 할 수 있습니다.
- 내부 탭은 재시작 후 자동 복원하지 않습니다.
- 로컬 PDF 열기는 확장 프로그램의 파일 URL 접근 설정에 영향을 받습니다.
- 자동 업데이트 서버는 없으며 설치 파일을 수동으로 업데이트합니다.

테스트 실행 방법은 README를 참고하세요. 실행 로그와 로컬 프로필은 저장소에 포함하지 않습니다.
